# binance_tracker
риложение с графическим интерфейсом (GUI) для отслеживания текущего курса криптовалют (BTC, ETH, BNB) в реальном времени с использованием API Binance. Программа позволяет вести учет собственных активов, сохраняя баланс в локальной базе данных.

## 🚀 Функционал
* **Мониторинг цен:** Получение актуальной стоимости криптовалют напрямую через публичное API Binance (Requests).
* **Учет портфеля:** Возможность добавлять, обновлять и удалять данные о количестве купленной валюты и цене покупки.
* **Локальное хранение:** Интеграция с СУБД SQLite3 для надежного сохранения данных между сессиями.
* **Современный UI:** Интерфейс выполнен в темной теме с использованием библиотеки `CustomTkinter` для плавного отображения виджетов.
