# Binance tracker
Приложение для отслеживания профита с крипто-бирж. Приложение создавалось с целью расчета прибыли от **полной** продажи валюты по курсу на настоящий момент. Работает на API binance

# Стек
* Python 3.11
* SQlite
* customtkinter
* API (requests)

# Функционал
* Сохранение покупок (имя валюты (BTC|ETH|BNB), цена на момент покупки, кол-во)
* Расчет текущей стоимости активов
